# Chatgpt-Quota-Card

[![发行校验](https://github.com/Shilem/Chatgpt-Quota-Card/actions/workflows/verify.yml/badge.svg)](https://github.com/Shilem/Chatgpt-Quota-Card/actions/workflows/verify.yml)

为 macOS Codex 客户端添加侧边栏额度卡片，并提供图形更新助手。客户端更新后，助手检查可用补丁，提醒你重新应用卡片。

> 适用于 **Codex 客户端**，部分安装沿用 `ChatGPT.app` 名称。普通 ChatGPT 聊天客户端不在支持范围内。

## 功能

- 企业类别账户显示 Monthly 剩余额度、本月用量和总额度；其他账户显示 5h、Weekly 剩余额度及重置时间。
- 卡片显示在侧边栏底部，侧边栏收起时隐藏。
- 图形助手支持查看状态、启停提醒、应用补丁、查看日志和备份。
- 助手自动获取本仓库发布的稳定更新；修改客户端前仍需你确认。
- 应用补丁前创建备份，支持恢复。

额度来自客户端已有数据，仅支持使用 ChatGPT 账户登录。企业类别由客户端套餐决定，不限制邮箱域名。

## 安装要求

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS，Apple Silicon（M系列芯片） |
| 客户端 | Codex；当前已验收版本为 `26.1007.21159` |
| 图形助手 | arm64 Node.js 22 或更新版本 |
| 网络 | 能访问 GitHub，供助手检查和下载更新 |

安装器会检查 Node.js；缺少兼容版本时提供官网安装入口，需要你按提示安装。

## 下载与安装

从 [最新稳定版](https://github.com/Shilem/Chatgpt-Quota-Card/releases/latest) 下载这两个文件：

```text
quota-user-assistant-installer-26.1007.21159-arm64.zip
quota-user-assistant-installer-26.1007.21159-arm64.zip.sha256
```

1. 在下载目录打开终端，核对文件完整性：

   ```bash
   shasum -a 256 -c quota-user-assistant-installer-26.1007.21159-arm64.zip.sha256
   ```

   显示 `OK` 后继续；失败时请重新下载。
2. 解压 ZIP，双击“额度卡片更新助手安装器.app”，选择客户端并确认安装。
3. 打开 `~/Applications/额度卡片更新助手.app`。
4. 选择“应用补丁”，按终端和弹窗提示完成首次卡片安装。

**安装助手后仍需首次应用补丁。** 关闭管理窗口不会停止后台提醒；可以在窗口中停用。

请下载上面列出的安装器，GitHub 的 `Source code` 归档不是图形安装器。

## 客户端更新后

助手每5分钟检查所选客户端。发现更新并确认客户端文件稳定后：

1. 检查本仓库是否有可用的稳定补丁，并自动更新助手。
2. 提醒你重新应用卡片。
3. 选择“应用补丁”并确认后，助手正常退出客户端、创建备份、应用补丁。
4. 检查成功后重新打开客户端。

**助手更新无需确认；退出和修改客户端必须由你确认。** 取消操作时不会退出客户端。更新检查失败、无法正常退出或补丁不兼容时，助手会停止并显示原因。

助手不会下载或安装官方客户端更新。遇到尚未支持的新版本，需要等待本项目发布适配补丁。

## 备份与恢复

在助手中打开备份目录，按恢复入口提示选择本工具生成的备份。单独补丁包也提供 `恢复额度卡片备份.command`；使用该入口前，请用 Command+Q 完全退出客户端。

助手的状态、日志和备份位于：

```text
~/Library/Application Support/Chatgpt-Quota-Card/user-assistant/
```

单独补丁包的备份默认位于解压目录的 `backups/`。备份可能占用数百MB，建议保留至少一份可用备份。

**恢复可以还原修改内容，不能恢复 OpenAI 官方签名。** 如果需要完整恢复官方版本，请重新安装官方客户端。

## 安全与限制

本项目会修改客户端文件，并使用本机临时签名。安装器没有 Apple Developer ID 签名，也未公证，macOS 可能阻止打开。请确认下载来源后按系统提示操作，不要关闭系统安全保护。

- 修改签名可能导致重新登录或钥匙串授权；系统推送和官方自动更新能力不能保证保留。
- 校验文件可以检查下载内容是否完整，不能代替发布者身份认证。
- 助手可能需要终端自动化权限；重新打开客户端后，请确认卡片和额度显示正常。
- 当前版本已通过自动检查和人工验收，未来客户端版本仍需重新检查兼容性。

更多说明见[安全及分发声明](NOTICE.md)。

## 常见问题

**安装后为什么没有提醒？**

助手只在客户端发生变化后提醒，平时保持安静。首次使用请主动选择“应用补丁”，并确认后台提醒已启用。

**为什么没有卡片或 Monthly 显示不可用？**

卡片仅支持 ChatGPT 账户登录。Monthly 取决于客户端的企业套餐分类，并非所有公司邮箱或付费账户都会显示。额度数据缺失、接口不可用或无限额度时可能显示不可用；请与客户端原生 Usage 页面核对。

**GitHub 检查失败怎么办？**

检查网络及仓库是否可访问，再手动检查更新。助手会暂停应用补丁，避免把“无法检查”当作“已经是最新”。

**客户端更新后应用失败怎么办？**

保留错误提示并检查是否有新补丁。若提示客户端签名或完整性异常，可重新安装官方客户端后再尝试；不要跳过检查强行应用。

**检查状态是什么意思？**

| 状态 | 操作 |
| --- | --- |
| `ready` | 可以按提示应用 |
| `already-patched` | 已应用，无需重复操作 |
| `upgrade-ready` | 旧补丁需要升级，可重新应用 |
| 检查失败 | 停止操作，保留错误提示并查看更新 |
